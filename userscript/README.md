# 油猴脚本版（Tampermonkey / Violentmonkey）

与浏览器扩展版功能对齐的单一脚本版本，适合不想装扩展、或需要在 Firefox / Safari 等浏览器使用的场景。

- 脚本文件：`cloudflare-imgbed-uploader.user.js`
- 版本：1.1.0
- 依赖：Tampermonkey、Violentmonkey 或兼容的用户脚本管理器

## 安装

1. 安装用户脚本管理器（[Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey）
2. 打开管理器的「添加新脚本」，把 `cloudflare-imgbed-uploader.user.js` 的内容整体粘贴进去并保存
   - 或把文件拖到浏览器窗口，管理器会提示安装
3. 首次运行会请求 `@connect *` 权限（需要访问你自建的图床域名与任意网页图片地址），点「总是允许」
4. 点击管理器图标 → 「⚙️ ImgBed 设置」填写 API 地址与认证信息

## 与扩展版的差异

| 能力 | 扩展版 | 油猴版 | 说明 |
|---|---|---|---|
| 图片右键菜单 | 原生菜单项 | 自绘菜单（默认接管） | 油猴无法注册浏览器右键菜单，改为在图片上右键弹出自定义菜单；按住 `Alt` 右键可临时使用原生菜单 |
| 剪贴板上传 | 右键 + `Ctrl+Shift+U` | 管理器菜单 + `Ctrl+Shift+U` | 剪贴板 API 被拒时自动降级为「按 Ctrl+V 粘贴」 |
| 拖拽上传 | ✅ | ✅ | 仅接管图片文件，不影响页面其他拖拽 |
| 分块上传 | ✅ | ✅ | Telegram 16MB/块，R2 / S3 / Discord 8MB/块 |
| 跨域抓图 | 后台 fetch | `GM_xmlhttpRequest` | 同样不受 CORS 与防盗链 Referer 限制 |
| 配置存储 | `chrome.storage` | `GM_setValue` | 不跨设备同步（除非开启管理器的同步功能） |
| 上传记录 | 独立窗口 | 设置面板内标签页 | 最多 200 条，仅本地 |
| 结果通知 | 页面内通知 | 页面内 Toast | 支持直链 / Markdown / BBCode 点击复制 |
| 深色模式 | ✅ | ✅ | 跟随系统 `prefers-color-scheme` |
| iframe 内 | 支持 | 不支持 | 脚本带 `@noframes`，只在顶层页面运行 |
| 浏览器特殊页 | 部分支持 | 不支持 | 油猴脚本无法注入 `chrome://`、扩展商店等页面 |

## 使用

### 入口一：图片右键菜单（默认开启）

在网页图片上点右键，弹出脚本自己的菜单：

- 上传此图片到 ImgBed
- 复制图片地址
- 在新标签页打开
- ImgBed 设置

菜单顶部会显示图片所在域名，避免误传。

> - 按住 `Alt` 再右键可跳过接管，使用浏览器原生的「图片另存为」等菜单
> - 在「⚙️ ImgBed 设置」里可以关掉「接管图片右键菜单」，恢复浏览器原生菜单
> - 除了普通 `<img>`，也能识别被透明层盖住的图片（很多站点的点击热区）以及 `background-image` 背景图

### 入口二：图片悬停按钮

鼠标悬停在图片上（宽高 ≥ 40px），右上角出现「上传到 ImgBed」，点击即可上传当前图片。

### 入口三：剪贴板

- 点击脚本管理器图标 → 「📋 上传剪贴板图片」
- 或按 `Ctrl+Shift+U`
- 若浏览器不允许直接读取剪贴板，会提示「请按 Ctrl+V 粘贴图片」，15 秒内粘贴即可

### 入口四：拖拽

把本地图片文件拖到页面任意位置即可上传，多张图片会依次上传。

## 配置项

与扩展版一致，全部在「⚙️ ImgBed 设置」中修改：

| 配置 | 说明 |
|---|---|
| API 地址 | 图床根地址，如 `https://img.example.com`，不要带 `/upload` |
| API Token | 管理后台创建，需 `upload` 权限，与认证码二选一（优先） |
| 上传认证码 | 服务端启用认证码时填写 |
| 上传渠道 | `telegram` / `cfr2` / `s3` / `discord` / `huggingface` / `webdav` |
| 渠道名称 | 同一渠道配置多个存储时指定 |
| 命名方式 | `default` / `index` / `origin` / `short` |
| 返回格式 | `full` 完整链接 / `default` 短链接 |
| 上传目录 | 如 `img/test`，留空为根目录 |
| 上传超时 | 10~300 秒 |
| 服务端压缩 | 仅 Telegram 渠道生效 |
| 失败自动重试 | 合并分块时对 5xx 重试，指数退避 |

文件大小上限：分块渠道 100MB，`huggingface` 20MB（≥20MB 需走直传流程，暂不支持），`webdav` 100MB。

## 已知限制

- **严格 CSP 的站点**：个别站点会拦截注入的 `<style>`，界面可能失去样式，但上传功能不受影响
- **剪贴板权限**：`navigator.clipboard.read()` 需要 HTTPS 页面且页面有焦点，被拒时会自动降级为粘贴模式
- **`@connect *`**：因为图床域名由用户自定义，脚本无法预先声明具体域名，安装时会请求连接任意域的权限
- **iframe 内的图片**：脚本带 `@noframes`，只在顶层页面运行，iframe 里的图片无法右键上传；可先把图片在新标签页打开
- **单文件脚本**：不参与扩展的自动更新，脚本更新需重新安装

## 本地验证

油猴版的上传链路已用 jsdom 做过端到端验证：

- 全流程回归（25 项）：配置保存、测试连接、单请求上传、9MB 分块上传、图片右键上传、记录渲染
- 右键上传专项（20 项）：默认配置即可右键、覆盖层图片、背景图、非图片区域不接管、`Alt` 放行、旧配置迁移、悬停按钮阈值

改动脚本后建议手动回归：右键上传、悬停按钮、剪贴板上传、9MB 以上文件分块。
